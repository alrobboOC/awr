Business Returns Service (BRS)

Use this service to:

  • file monthly BRS returns
  • file nil returns (when you have made no payments)
  • view and manage workers
  • amend returns you have already submitted
  • view notices and statements
  • appeal against late-filing penalties
  • save incomplete returns
{{ govukInsetText({ text: "You must file BRS returns for each tax month, by the 19th of the following month." }) }}

Before you start

To use this service, you need:

  • to be authorised to act for your clients
  • a tax office reference or Unique Taxpayer Reference (UTR)
  • details of payments made to workers during the tax month
