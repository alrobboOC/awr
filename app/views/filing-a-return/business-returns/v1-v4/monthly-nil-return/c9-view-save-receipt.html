View and save the submission receipt

You have chosen to view your Submission Receipt. Your browser automatically shows a copy of the file in the computer's 'Temporary Internet Files' cache.

We suggest that if you are not using your own computer, or have concerns about the security of the computer, you delete the file once you have viewed your Submission Receipt.

The most common way of doing this is to select 'Tools' from the browser menu, then select 'Internet options' followed by 'Delete Files' under the 'Temporary Internet Files' section.

If these instructions are not applicable to the browser you are using please refer to the 'Help' section in your browser, which should give instructions on how to do this.
