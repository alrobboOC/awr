Monthly return

The monthly returns journey allows businesss to report payments made to workers during a tax month. Businesss select the tax period, choose which workers to include, enter payment and deduction details, and submit their return by the 19th of the following month.

All screens
  • MR02a - Introduction
  • MR02b - Enter tax month
  • MR0301 - Last return workers
  • MR0302a - Select workers (variant a)
  • MR0302b - Select workers (variant b)
  • MR0302c - Select workers (variant c)
  • MR0303h - Unverified workers
  • MR0303a - Workers paid
  • MR0303c - Total payments made
  • MR0303d - Cost of materials
  • MR0303e - Total tax deducted
