Monthly return

The monthly returns journey allows contractors to report payments made to subcontractors during a tax month. Contractors select the tax period, choose which subcontractors to include, enter payment and deduction details, and submit their return by the 19th of the following month.

All screens
  • MR02a - Introduction
  • MR02b - Enter tax month
  • MR0301 - Last return subcontractors
  • MR0302a - Select subcontractors (variant a)
  • MR0302b - Select subcontractors (variant b)
  • MR0302c - Select subcontractors (variant c)
  • MR0303h - Unverified subcontractors
  • MR0303a - Subcontractors paid
  • MR0303c - Total payments made
  • MR0303d - Cost of materials
  • MR0303e - Total tax deducted
